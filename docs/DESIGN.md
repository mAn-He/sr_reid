# 연구 설계 (Stage 0.5 확정본)

사용자가 Stage 0.5 지시서에서 확정한 설계입니다. 이 문서는 지시서를 옮긴 것이며, 임의로 바꾸지 않습니다.

## 1. 데이터 출처
- Market-1501 원본(128×64). 배율 k는 원본 기준입니다.
- 표준 입력 이미지를 다시 SR하지 않습니다.

## 2. 기준선
학습하지 않습니다. 각 모델의 공개 가중치를 공식 입력 크기로 평가한 값을 참고 행으로 씁니다.

| 모델 | 공식 입력 (H×W) | 표기 |
|---|---|---|
| BoT | 256×128 | 원본 ×2 |
| CLIP-ReID | 256×128 | 원본 ×2 |
| KPR | 384×128 | "KPR 공식 설정" |
| KPR+SOLIDER | 384×128 | "KPR 공식 설정" |

기준선과의 차이는 참고용입니다. 결론은 우리가 학습한 S_k와 C_k의 비교로만 냅니다.

## 3. SR 비교 배율
| 배율 | 입력 (H×W) | 표준 입력(256×128) 대비 |
|---|---|---:|
| ×3 | 384×192 | 1.5배 |
| ×4 | 512×256 | 2.0배 |

- SR 출력 크기가 모든 모델의 네트워크 입력 크기입니다.
- 모델 안에서 다시 리사이즈하지 않습니다. 4개 모델 모두 같은 규칙이며, KPR 기본값 384×128은 기준선에만 씁니다.

## 4. 학습 조건 (배율마다)
- **C_k:** train·test 모두 bicubic ×k
- **S_k:** train·test 모두 SR ×k (SR 2종). query와 gallery 모두 SR 이미지

평가 전용 조건 (추가 학습 없음):
- S_k 모델 + bicubic test (train만 SR)
- C_k 모델 + SR test (test만 SR)

## 5. ReID 모델
BoT, CLIP-ReID, KPR, KPR+SOLIDER.

## 6. seed
모든 학습은 seed 42로 고정합니다. 다른 seed와 판정 규칙은 Stage 0.5에서 다루지 않습니다.

## 7. 결과 해석 축
SR 품질(보존 지표) × ReID 향상 여부의 2×2 해석.

## 절대 규칙
- 학습 레시피 변경 금지(입력 크기 제외): 배치, PK 샘플링, 학습률, 스케줄, epoch, 옵티마이저, 정밀도, 증강의 종류·순서·확률·파라미터.
- 외부 모델 소스 수정 금지. 변경은 config, 래퍼, 서브클래스, 어댑터에서만 합니다.
- test 가드 유지. 예외는 공개 가중치로 공식 test를 평가하는 것(기준선, 등가성·RAM 측정)과 test 이미지의 SR 생성(평가·열람 없이 파일 생성만)뿐입니다.
- 이미지 외부 전송 금지. 이미지는 열지 않고 수치로만 검사합니다.
- tmux 실행·재개 가능 구조. 실패도 결과로 기록합니다.
